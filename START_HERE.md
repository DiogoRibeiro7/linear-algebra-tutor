## 🚀 Quick Start (3 Steps)

### 1. Download
✅ **The project folder is ready in your outputs.**

Click on the `linear-algebra-tutor` folder above to download.

### 2. Setup
```bash
cd linear-algebra-tutor
./setup.sh
# Edit .env and add ANTHROPIC_API_KEY
python scripts/generate_embeddings.py
```

### 3. Run
```bash
# Terminal 1 - Backend
cd backend && source venv/bin/activate && python -m app.main

# Terminal 2 - Frontend
cd frontend && yarn dev

# Open: http://localhost:5173
```

**Full instructions:** See `TRANSFER_GUIDE.md`
